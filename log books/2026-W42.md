## [10/20/2027] - Linux Fundamentals sections 1-5

Date: [10/20/2027] | Module: Linux Fundamentals | Sections: 1-5 | Time: [60] min

Learned:
- **Linux structure (1):** Linux is an OS built around the kernel. Its philosophy: everything is a file, small single-purpose programs, chain programs together, avoid captive user interfaces, and keep configuration in text files.
- The main components are the bootloader, kernel, daemons, shell, graphics server, window manager and utilities. The architecture is layered: hardware, kernel, shell, system utilities.
- The file system hierarchy starts at `/`. Key directories: `/etc` (configuration), `/home` (user files), `/root` (root's home), `/var` (logs and variable data), `/tmp` (temporary files), `/bin` and `/sbin` (binaries), `/dev` (devices), `/opt` (optional software).
- **Distributions (2):** a distro is an OS built on the Linux kernel. Examples are Ubuntu, Debian, Fedora and Parrot OS. Debian uses the `apt` package manager and is known for stability. Kali Linux is a popular distro for security work.
- **Shell (3):** a shell (command line) is a text interface between the user and the kernel. A terminal emulator runs a shell inside a window, and multiplexers such as Tmux split one terminal into several. Bash (Bourne-Again Shell) is the most common shell; others include Zsh, Ksh, Fish and Tcsh/Csh.
- **Prompt (4):** the default prompt shows `username@hostname[directory]$`. `~` means the home directory. `$` is a normal user and `#` is root. The `PS1` variable controls the prompt format, for example `\u` (user), `\h` (host) and `\w` (working directory), set in `.bashrc`.
- **Getting help (5):** `man <tool>` opens the manual, `<tool> --help` (or `-h` for some tools like `curl`) gives a short summary, and `apropos <keyword>` searches manual descriptions. explainshell.com breaks down long commands.

## [11/20/2027] - Linux Fundamentals sections 6-10

Date: [11/20/2027] | Module: Linux Fundamentals | Sections: 6-10 | Time: [45] min

Learned:
- **System information (6):** `whoami` (current user), `id` (user and group memberships), `hostname`, `uname -a` (system details; `-r` for the kernel release), `pwd`, `ifconfig` and `ip` (network interfaces), `netstat` and `ss` (connections), `ps` (processes), `who` (logged-in users), `env`, `lsblk`, `lsusb`, `lsof` and `lspci`. I connect to the target with SSH.
- **Navigation (7):** `pwd` shows where I am, `ls` lists files, `ls -l` adds details, and `ls -la` also shows hidden files (names starting with a dot). `cd <dir>` moves, `cd -` jumps back, `.` is the current directory and `..` is the parent. Tab completion saves typing, `clear` or `Ctrl+L` clears the screen, and `Ctrl+R` searches command history.
- **Working with files and directories (8):** `touch` creates a file, `mkdir` creates a directory (`-p` creates parent directories too), `tree` shows the structure, `mv` moves or renames, and `cp` copies.
- **Editing files (9):** Nano is the simple editor (`Ctrl+W` search, `Ctrl+O` save, `Ctrl+X` exit). `cat` prints a file. Vim is modal, with Normal, Insert, Visual, Command, Replace and Ex modes. `:q` closes it and `vimtutor` is the built-in practice tutorial.
- **Finding files (10):** `which` shows where a program lives. `find` searches by type, name, owner, size and date, and can run a command on each result with `-exec`. `locate` is faster because it uses a database that `sudo updatedb` refreshes, but it has fewer filters.
