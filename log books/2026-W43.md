## [22/10/2027] - Linux Fundamentals sections 11-15

Date: [22/10/2027 | Module: Linux Fundamentals | Sections: 11-15 | Time: [60] min

Learned:
- **File descriptors and redirections (11):** every process has three standard streams: `STDIN` (0), `STDOUT` (1) and `STDERR` (2). `>` sends output to a file and overwrites it, `>>` appends, `<` feeds a file in as input, and `<< EOF` passes text from the terminal. `2>/dev/null` throws away error messages. A pipe `|` sends one command's output into another, for example `find ... | grep ... | wc -l`.
- **Filtering contents (12):** `more` and `less` page through files, `head` and `tail` show the start and end, `sort` orders lines, `grep` searches (`-v` excludes matches), `cut` takes fields by delimiter, `tr` swaps characters, `column -t` tidies output into a table, `awk` picks columns, `sed` substitutes text, and `wc -l` counts lines.
- **Regular expressions (13):** regex describes text patterns. `( )` groups, `[ ]` is a character class, `{ }` sets how many times, `|` is OR, and `.*` joins two parts in order (like AND). With `grep`, I need `-E` for extended regex.
- **Permission management (14):** each file has read (r), write (w) and execute (x) permissions for owner, group and others. `chmod` changes them using letters (`a+r`) or octal numbers (r=4, w=2, x=1, so 754 means rwx for owner, r-x for group, r-- for others). `chown user:group` changes ownership. SUID and SGID make a program run with the owner's or group's rights, and the sticky bit stops users deleting each other's files in a shared directory.
- **User management (15):** `sudo` runs a command with another user's rights (usually root), `su` switches user, `useradd`, `userdel` and `usermod` manage accounts, `addgroup` and `delgroup` manage groups, and `passwd` changes a password. `/etc/shadow` holds password data and only root can read it.

## [23/10/2026] - Linux Fundamentals sections 16-17

Date: [add date] | Module: Linux Fundamentals | Sections: 16-17 | Time: [add] min

Learned:
- **Package management (16):** packages are archives of programs and their configuration. `dpkg` installs a single `.deb` file, `apt` is the higher-level tool that also handles dependencies, and `aptitude`, `snap`, `gem`, `pip` and `git` cover other kinds of software. Useful `apt` commands: `apt-cache search`, `apt-cache show`, `apt list --installed` and `sudo apt install`. Repositories are listed in `/etc/apt/sources.list` and `/etc/apt/sources.list.d/`. I can download a tool with `git clone`, or fetch a `.deb` with `wget` and install it with `sudo dpkg -i`.
- **Service and process management (17, in progress):** services (daemons) run in the background and are managed by `systemd`. `systemctl` starts, stops, checks, enables (start at boot) and lists services, and `journalctl` shows their logs. `ps` lists processes. `kill` sends a signal to a process (for example `SIGTERM` to ask it to stop, `SIGKILL` to force it). `Ctrl+Z` suspends a job, `bg` resumes it in the background, `fg` brings it back, `jobs` lists them, and `&` starts a command in the background. Commands can be chained with `;` (always run the next), `&&` (run the next only if the first succeeded) and `|` (pipe).
